## 🚀 Daily Workflow

When solving a new problem:

1. Create a new folder under `src/` following the format `XXXX-Problem-Title` (e.g., `src/0001-Two-Sum`).
2. Add:
   - `Solution.java` (your Java solution)
   - *(Optional)* `README.md` with problem statement and time/space complexity analysis.
3. Update the tracker table above.
4. Commit and push:
   ```bash
   git add .
   git commit -m "Add LeetCode XXXX: Problem Name"
   git push
   ```
